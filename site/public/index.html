Agent Errors

Machine-readable errors for AI agent harnesses

An AI agent runs a language model inside a harness. The harness parses model output, calls tools, manages context, and enforces limits. When something fails in this layer, such as malformed structured output, an exceeded turn limit, or context overflow, each implementation reports it differently. Many of them classify upstream failures by matching message text.

Agent Errors defines a single error object for these failures. It is built on Problem Details (RFC 9457), carries a stable error code, and says whether the error is transient and whether the model can repair it. It also defines bindings to the Model Context Protocol and the Agent2Agent protocol.

Example

{
  "type": "https://agenterrors.org/problems/harness-error",
  "title": "Output Schema Violation",
  "code": "output.schema_violation",
  "origin": "model",
  "retryable": false,
  "model_recoverable": true,
  "model_feedback": "Field 'price' must be a number, got string.",
  "location": { "turn": 5, "pointer": "/items/0/price" }
}
